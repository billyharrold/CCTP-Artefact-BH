# CCTP-Artefact-BH

This repository contains all source files for the research artefact made in response to the question: Investigating the effect of adaptive information delivery systems in commercial games. 

The artefact is designed to be played with an Xbox controller connected as all input prompts are linked to their icons. However mouse and keyboard controls are still active and can be used. 

All assets within the ‘StarterAssets’ folder belong to the Unity third-person controller package and within the ‘Kenney Platforming Assets’ are externally created (see appendix C). 
All other assets and scripts within the project have been made by the researcher. 

There are two main scenes: StaticScene and AdaptiveScene. In the adaptive scene you will find the adaptive system working and present, and the StaticScene is the designed control condition without the system present. 
The scenes are found in Assets/Prefabs/Scenes.

The build files attached to the report contains a menu with a choice of the level containing the adaptive system and a control level without it present. The study was designed for a participant to only play one, therefore once the level is complete it quits to desktop. To play again it requires the executable to be opened again.
